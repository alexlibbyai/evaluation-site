> Interactive evaluation and decision-support dashboard for steganalysis research, model assessment and forensic experimentation.

The **Evaluation Dashboard** provides a unified interface for analysing and comparing results generated by the StegoForge/ImageSNN/ImageCNN ecosystem. Designed to support both technical evaluation and analyst workflows, the dashboard combines performance metrics, confidence assessment, calibration analysis, explainability outputs and triage support within a single environment.

The platform was developed to support comparative evaluation of **ImageCNN** and **ImageSNN** steganalysis frameworks whilst promoting transparency, reproducibility and human-centred interpretation of automated classifications.

- 📊 Interactive model evaluation dashboard

## 🚀 Installation

### Clone the Repository

```bash
git clone https://github.com/alexlibbyai/evaluation-dashboard.git
cd evaluation-dashboard
```

### Create a Virtual Environment

```bash
python -m venv .venv
```

### Activate the Virtual Environment

#### Windows

```bash
.venv\Scripts\activate
```

#### Linux / macOS

```bash
source .venv/bin/activate
```

### Install Runtime Dependencies

```bash
pip install -r requirements.txt
```

### Install Development Dependencies

```bash
pip install -r requirements-dev.txt
```

## 📊 Dashboard Capabilities

### Model Performance Assessment

The dashboard supports evaluation of standard machine-learning performance metrics, including:

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrices
- ROC Analysis
- AUC Visualisation

### Confidence and Calibration

The platform provides confidence-aware evaluation through:

- Confidence scoring
- Percentile ranking
- Calibration analysis
- Confidence distribution visualisation
- Reliability assessment

### Explainability and Transparency

Supported explainability workflows include:

- Grad-CAM visualisations
- Classification inspection
- Comparative decision analysis
- Confidence interpretation
- Model transparency assessment

### Forensic Triage Support

The dashboard supports analyst workflows by providing:

- Confidence-based prioritisation
- Triage category assignment
- Comparative image review
- Classification summaries
- Decision-support visualisations
